## Sobre

Apresentação profissional, tecnologias em desenvolvimento e projetos práticos com foco em backend, APIs REST e bancos de dados.

## Tecnologias do site

- HTML5 semântico
- CSS3 responsivo, animações e acessibilidade para movimento reduzido
- JavaScript puro
- GitHub Pages

## Publicação

O repositório precisa ter o GitHub Pages habilitado em **Settings → Pages → Build and deployment → Deploy from a branch**, selecionando a branch `main` e a pasta `/(root)`.

Após salvar, o GitHub disponibiliza o site em:

`https://victordev145.github.io`
